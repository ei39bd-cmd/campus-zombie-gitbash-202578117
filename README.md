# Campus Zombie Survival

좀비 바이러스가 확산된 대학 캠퍼스에서 살아남아 도서관 옥상으로 탈출하는 텍스트 기반 게임 기획입니다.

## 게임 목표

- 좀비를 피해 도서관 옥상까지 이동합니다.
- 체력을 관리하고 랜덤 이벤트에서 생존 전략을 선택합니다.
- 마지막 선택과 감염 상태에 따라 서로 다른 엔딩에 도달합니다.

## 기획 파일

- `game/rules.md`: 기본 규칙
- `game/events.md`: 랜덤 이벤트

Git Quest 실습 프로젝트이며 실행 가능한 게임 프로그램은 포함하지 않습니다.

## 게임 플레이 팁

- 학생회관에서 구급함을 확보하고 체력 소모가 큰 길은 우회하세요.
- 도서관 앞에서는 소음을 줄여 감염 위험을 피하세요.
- 체력과 감염 상태를 확인하고 도서관 옥상으로 이동하세요.
